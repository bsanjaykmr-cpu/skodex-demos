# RS BRAND catalogue demo

Static customer demo using catalogue images, descriptions and retail-facing prices shared in the WhatsApp export. Dealer-specific “UR PRICE” values, phone numbers and private chat details are excluded. A typographic RS BRAND mark is used because the export did not include a standalone brand logo.

The served demo can be disabled without losing the work: tag or archive the current revision, replace this directory with a small unavailable page, and remove deployed assets from this path. The full source remains recoverable from Git history or the archive tag. Restoring the tagged directory re-enables the demo.
