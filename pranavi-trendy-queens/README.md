# Pranavi Trendy Queen's Choice — Demo Catalogue

Premium static ecommerce catalogue demo built from the supplied WhatsApp export.

- Uses real catalogue product images, descriptions and retail prices.
- Includes 16 latest pieces across four collections and three shortened catalogue videos.
- Responsive four-column desktop and two-column mobile grids.
- Client-side search, filters, saved pieces and product detail modal.
- No checkout or payment processing.

The transparent logo asset was extracted from the supplied Pranavi logo card. Internal dealer-only discount notes were intentionally not published.
