# VIBHA Designer Couture demo

Buildless catalogue preview. Open index.html through a static server. Retail catalogue prices from 17 November 2026 are shown; dealer-specific prices and private chat data are excluded. Product selections are catalogue photographs, not claims of distinct stock units. Blouse/pallu information is only shown where supplied. The typographic VIBHA wordmark is a demo treatment; no standalone brand logo was identified among the selected catalogue assets.

To disable: preserve this directory in a Git tag or archive branch, then replace the served directory with an unavailable page and remove its deployed assets. Commit and push. Do not disable the repository's Pages site, which hosts other demos. Source remains recoverable in Git history. Re-enable by restoring this directory from the saved revision.
